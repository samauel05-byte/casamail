# Descargas de CasaMail

Última versión: **https://github.com/samauel05-byte/casamail/releases/latest**

| Sistema | Archivo |
|---|---|
| Windows | `CasaMail-Setup-x.y.z.exe` (instalador) |
| macOS | `CasaMail-x.y.z.dmg` |
| Linux | `.AppImage` o `.deb` |
| Android | Google Play (próximamente) |

Si no está firmado: en Windows pulsa **Más información → Ejecutar de todas formas**; en macOS, si dice «dañado», ejecuta `xattr -cr /Applications/CasaMail.app`. Ver [FIRMA-INSTALADORES.md](FIRMA-INSTALADORES.md).

CasaMail **avisa** cuando hay una versión nueva (consulta solo GitHub; se puede desactivar con la variable `CASAMAIL_NO_UPDATE_CHECK=1`).
